# 听准 Implementation Plan（实现计划）

Goal（目标）：实现 design.md 所述首版并提供可打开的网址和源文件。
Architecture（架构）：静态原生 JavaScript（脚本语言）模块；音乐数据、检测、跟谱、分析、音频和存储分离；音频不上传。
Spec（设计）：docs/design.md。

- [ ] 1. 音乐核心：先编写失败测试，再实现简谱／电子谱导入、音高检测、时间线、自由跟谱与分析。运行 node --test。
- [ ] 2. 音频与本地记录：实现统一时钟的播放与采集、录音、持久化及备份，验证文件往返和无声情形。
- [ ] 3. 应用界面：实现谱面、模式配置、实时图、历史与复盘；用浏览器实际操作验证。
- [ ] 4. 完整审查、修复与测试；打包、发布公开版本，并保留可在其他免费静态托管使用的源码。

重点边界：同旋律的不同谱段不强行定位；评分不以正负误差抵消；停顿与无声不计跑调；慢唱不能全变错音；音频权限失败要停止资源；循环与选段不能留下上一轮声音；导入不执行文件内代码；保存失败不能显示成功。
