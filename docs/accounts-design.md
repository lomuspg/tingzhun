# 游客与个人账号 · v0.2

用户选择：游客可用，登录后同步记录；完全免费，不同用户不能看到彼此记录。沿用“直接制作”的授权，不增加设计审批。

当前记录按浏览器源隔离；同浏览器、同网址的游客共享本机记录。此版增加服务端账号隔离，并区分游客本机数据与账号数据。

## 实现边界

- 主站使用 Sites 托管认证的 ChatGPT 登录，不自建密码、短信或邮件登录。保持网页公开，游客仍可练唱。
- GitHub Pages 无服务端，保留游客功能；账号入口跳转主站，并提示两个网址的本机数据独立。
- 同步个人偏好和练习摘要（含曲谱和小节结论）。原始录音与完整采样曲线不上传，换设备显示“云端摘要，录音在原设备”。
- 服务端每次读写从认证请求获取用户标识，全部 SQL 带该标识；不接受客户端指定记录所属用户。未登录读写返回 401，不开放跨域凭据访问；写操作校验来源，阻止跨站请求。
- 本机旧记录迁移为游客记录；账号数据用每账号密钥加密后保存，密钥仅在已登录内存中持有，账号密钥不写入浏览器存储或备份。切换身份后列表和播放器清空再加载。
- 用户主动点击才把游客旧记录复制到当前账号；不自动合并。
- 免费容量硬限制：每人最多 100 条摘要、2 MB 摘要总量；全站摘要总量 40 MB；单条最大 128 KB。达到限制时保持本机录音并停止新增同步，不升级付费服务。
- 不使用付费模型、短信、邮件或音频云存储，不开启自动付费升级；托管平台可用性仍受其服务政策和免费资源限制影响。

## 交互

右上角“游客 · 本机保存 / 登录同步”。登录后显示昵称、同步状态与“我的偏好”。偏好包含默认练唱模式、旋律/伴奏音量、音准容差。每首谱的速度和升降调保留在练习记录条件中。

同步状态可区分：游客本机保存、已同步摘要、待重试、免费容量已满、登录已失效。退出前提醒本机录音仅能在相同账号登录后读取，可以先导出备份。

## 验证

- 两个服务端账号的读取、删除和同名记录隔离；匿名拒绝、伪造 owner 字段拒绝、容量与跨站写入测试。
- 旧游客迁移、账号本机加密、切换账号、备份去除身份和密钥、录音完整还原。
- 集成测试模拟登录与云端成功/失败；确保原练唱流程不回归。
- 生产匿名及伪造身份请求均应拒绝访问账号接口。真实登录须在用户浏览器检查，不把模拟身份测试当作真人登录成功证据。
