# 听准第一版功能与设计 · 2026-11-17

用户授权：先汇总本次讨论，随后直接实现第一版，不再次设置设计审批。

目标：免费、无付费接口、本地处理声音的公开网页练唱工具。支持连续整段演唱、任意起唱与跳段定位、稳定节奏声音、钢琴伴奏选段播放、实时反馈和录音复盘保存。

## 首版行为

- 中文界面，首次出现英文技术术语配中文解释。淡纸色、墨绿、珊瑚色界面，谱子和练唱是主体。
- 导入 MusicXML、MXL 压缩电子谱和文本简谱；展示可选声部，区分旋律与伴奏。简谱支持调号、拍号、速度、和弦、八度、减时线、附点、延长和休止。
- 原始图片或 PDF 作为对照附件；首版不声称已实现图像自动识谱，提示需要电子谱或简谱文本。
- 自由／节拍／钢琴三种模式。选小节范围、调速、升降调、循环、预备拍、旋律与伴奏独立音量。钢琴按预定时间轴播放，不随演唱改变。
- 有伴奏声部按谱播放；有和弦时按和弦生成基础伴奏；只有旋律时只弹旋律，不假称原曲伴奏。独立的推测和声不纳入首版。
- 麦克风实时音高、偏差、曲线、检测可信度；自由定位试用算法支持从任意位置开始、跳段和重复，相同旋律保留歧义。未可靠定位时不评分。
- 录音和帧数据共用时钟；有声帧可分析比例、音准方向、问题片段、规则生成总结；自由模式不提供固定速度节奏成绩。循环每轮记录，未唱部分不扣分。
- 录音回放与曲线同步，点击问题跳转，目标试听。本机 IndexedDB（浏览器本地数据库）持久化、容量失败报错、完整 JSON（结构化数据）备份含录音及导入、单独音频与报告导出、删除记录。不开通云存储。

## 验证

自动化验证真实计算：简谱节奏与调号，MusicXML 声部/时值/连音/和弦，合成声音的音高检测，任意起点/跳段/重复歧义定位，评分不抵消、无声不伪造、选段时间线与循环。界面通过真实浏览器操作验证；真人声音和手机体验标为未验证。
