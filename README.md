# 听准 · 第一版试用

免费静态网页练唱工具。音高分析、钢琴合成、录音和练习记录在访问者设备本地处理，无付费接口或音频上传。

## 打开

推荐访问已发布的网址。自行运行：在本目录执行 `node server.mjs`，用浏览器打开 http://127.0.0.1:4173 。Node.js（JavaScript 运行环境）仅用于本机静态服务；访问已托管网页无需安装它。不要直接双击 index.html，浏览器模块和麦克风需要安全网页或本机服务。

## 功能

- 内置传统旋律及原创练习。导入 .musicxml / .xml / .mxl 电子谱或 .txt 简谱；可选择练唱声部。
- 自由练唱、节拍练唱、钢琴伴奏三种模式。钢琴不跟随用户改变速度。任意连续小节选段、循环、预备拍、速度与升降调、独立旋律/伴奏音量、暂停继续。
- 有谱面伴奏声部时照谱播放；只有和弦时生成基础分解伴奏；只有旋律时只提供旋律提示。声音为本机合成钢琴音色。
- 音高曲线、目标音、偏高/偏低提示、自动定位试用。持续录音与本机保存，回放曲线、重点小节、目标试听与规则生成总结。
- 完整备份包含录音与分析，支持导出导入；可单独下载录音和 HTML（网页文档）报告。本机记录可删除。
- 使用指南附本机自检页面，使用合成音，不调用麦克风；可测试浏览器实际音频编码与本地存储。

## 首版边界

- 图片和 PDF 是对照附件，暂不自动识谱。附上对照文件并不会替换当前练唱旋律。
- 自由起唱、跳段和重复定位使用最近音高序列匹配，尚未验证真实歌声下的准确率；连唱、重复音、装饰音或较多错音可能跟丢；完全相同的旋律保留歧义，不强行评分。
- 电子谱按谱面小节顺序、所选固定速度播放。反复展开、装饰音、谱面变速尚未完整支持；导入后先检查警告和试听。
- 音准标准为可调整的练习容差，不是声乐专业评级。进拍差异为试用估计，未经过实际设备延迟校准；自由模式不提供固定速度节奏分。
- 简谱支持大调首调文本；复杂调性建议使用电子谱。五线谱是便于练唱的简化视图。
- 当前记录仅保存在当前浏览器，不跨设备自动同步。清理浏览器数据可能丢失记录，应导出备份。一次录音最长约 30 分钟；手机切后台、锁屏可能中断。
- 建议戴耳机；外放琴声可能影响麦克风音高检测。未完成真人练唱或真实手机兼容性验证。

## 开发验证

安装开发依赖：`npm ci`；运行测试：`npm test`。浏览器入口 `checks.html` 提供实际音频与存储自检。自动化测试包括合成音高、谱子解析、跳段歧义、统计、录音生命周期、备份类型和导入校验，以及模拟浏览器环境的应用流程。
